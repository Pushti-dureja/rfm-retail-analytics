# Retail Customer Segmentation & Analytics Project

## Objective
Analyze retail customer behaviour and create customer segments using RFM analysis.

## Tools Used
- Python
- SQL
- Excel
- Power BI
- Tableau
- SPSS
- AWS

## Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. RFM Segmentation
5. Dashboard Creation
6. Statistical Analysis
7. Cloud Deployment

## Key Insights

- High value customers identified
- Customer purchasing patterns analysed
- Revenue trends discovered
- Customer retention strategies suggested

## Conclusion
Data-driven recommendations for improving customer retention and sales.
